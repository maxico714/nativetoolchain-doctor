# Support

## Getting Help

- **Bug reports**: Use the [Bug Report](.github/ISSUE_TEMPLATE/bug.yml) issue template
- **Feature requests**: Use the [Feature Request](.github/ISSUE_TEMPLATE/feature.yml) issue template
- **Questions**: Open a GitHub Discussion (if enabled) or a feature request issue

## What to Include

For bug reports, please include:

1. The exact command you ran
2. The full output (stdout and stderr)
3. Your Windows version (`ver` or `systeminfo`)
4. Python version (`python --version`)
5. Whether Visual Studio Build Tools and Windows SDK are installed
6. A `--bundle` output file if possible (review it first for sensitive data)

## Response Time

This project is maintained by volunteers. There is no SLA. We aim to:

- Acknowledge issues within 7 days
- Triage and label within 14 days
- Fix critical bugs in the next patch release

## Commercial Support

No commercial support is offered. If you need guaranteed response times, consider engaging a consultant familiar with Windows native build toolchains.
